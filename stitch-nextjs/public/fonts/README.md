# Licensed fonts (pending)

Sequel Wide and Sequel Sans are NOT installed. No licensed webfont files for them were found in this project, and none were downloaded.

If licensed `.woff2` files are supplied, add `@font-face` rules for the families `"Sequel Wide"` and `"Sequel Sans"` in `src/app/(dashboard)/dash.css`.
The font stacks already list those names first, so they will take over without other changes.

Current fallbacks (SIL OFL, loaded from Google Fonts): Unbounded (display), Hanken Grotesk (sans), JetBrains Mono (technical identifiers).
