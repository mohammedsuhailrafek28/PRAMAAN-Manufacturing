### P2 semantic notes (documented, not blockers)
1. F5 supplier packages disclose the local canonical lot/supplier id; F6 responses are counts-only. Separate explicit channels; a factory wanting F6's minimal disclosure should not also issue F5 supplier packages (tested, `p2ChannelDifference`).
2. F5 customer package for an identity-guard-only hold shows `evidenceFinding=EXCLUDED_WITH_EVIDENCE` with `operationalAction=RECALL_HOLD` (frozen values; could be misread). F5 supplier package is refused for such a motor.
3. F6 staging temporarily sets `service.DEFAULT_LOT_REGISTRY`; restored (tested). F5 takes the registry explicitly.
4. F5 issuance is refused while a ledger is newer than its checkpoint (e.g. after F6 adoption until the checkpoint cycle) and for RELEASE_ELIGIBLE motors (tested).
5. Historical `CI_INVENTORY_CHANGE_F5/_F6.md` still name the old per-feature lock files.
